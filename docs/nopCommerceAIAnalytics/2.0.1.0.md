# Version 2.0.1.0

| **Release Date**                  | June 2026            |
|-------------------------------------|-------------------------|
| **Plug-In Version**                 | 2.0.1.0                 |
| **Supported nopCommerce Version**   | 4.90                    |

### What's New:

1. Renamed to **nopCommerce AI Analytics**; the AI chat screen is now the **AI Analytics Workspace**.
2. Expanded Analytics Dashboard with Sales Performance, Customers, and Operations & Health card groups (Total Revenue, Total Orders, Average Order Value, Avg. Items Per Order, Returning Customer Orders, New Registrations, Active Customers, Pending Orders, Cart Items Updated, Average Customer Lifetime Value, Customer Retention Rate, Return Requests, Discount Usage).
3. New Order status, Payment method, and Shipping method breakdown donut charts.
4. New vs returning customer orders chart and Customer registrations trend chart.
5. New Top categories and Sales by region ranked tables, alongside the existing Top products table.
6. AI Analytics Workspace now confirms ambiguous details before running an analysis, and only generates charts when explicitly requested.
7. New **Saved Prompts** panel for one-click access to recurring reports and business questions.
8. New **Recent Prompt Activity** log tracking every AI Analytics Workspace question, its timestamp, and status (Success / Needs Clarification).
9. Added CSV and PDF export for AI Analytics Workspace answers, alongside existing Excel export from the dashboard.
10. Configuration screen redesigned with General settings, AI analytics settings, and a Data scope notice; License registration and status display added.
11. Added Prompt log retention (days) setting to control how long AI Analytics Workspace history is kept.
12. Added OpenAI (ChatGPT) as a selectable AI provider alongside Anthropic, OpenRouter, Azure OpenAI, and Custom/Self-hosted.
13. Added dedicated admin permission to restrict access to Configuration, Dashboard, and Workspace screens.
