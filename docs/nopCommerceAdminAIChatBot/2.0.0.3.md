# Version 2.0.0.3

| **Release Date**                  | 2025              |
| --------------------------------- | ----------------- |
| **Plug-In Version**               | 2.0.0.3           |
| **Supported nopCommerce Version** | 4.90+ / .NET 9.0+ |

### Features:

1. AI Chat Engine connected to 200+ models via OpenRouter with real-time streaming responses.
2. 73 pre-built store management tools across Catalog, Orders, Customers, Promotions, ContentManagement, Configuration, System, and Unrestricted categories.
3. Admin Knowledge Base with auto-indexing of admin pages, store settings, and service dependencies via Sync Sitemap, Sync Settings, and Sync Service Dependencies.
4. Floating Admin Bot widget embedded in the nopCommerce admin panel with configurable welcome message and max message length.
5. AI Processing Logs — per-message logs with intent detection, confidence score, action taken, status, error detail, and response time.
6. Write Confirmation — all store-modifying actions require explicit user approval before execution.
7. Role-based permissions with granular per-feature and per-tool access controls.
8. Multi-store support with per-store setting overrides.
